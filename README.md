# JD Cosmetic – Prototyp des Shops

**Entwurf – nicht der offizielle Shop von JD Cosmetic.**

Klickbarer Prototyp für das neue Erscheinungsbild des Online-Shops von JD Cosmetic. Der offizielle Shop läuft
weiterhin unter jdcosmetic.de; dieser Prototyp dient nur zur Abstimmung. Texte, Preise und Gestaltung sind vorläufig.
Bestellen ist hier nicht möglich.

- Ansicht: `https://kremer-consulting.github.io/jdcosmetic-prototype/`
- Lokal: [`index.html`](index.html) im Browser öffnen

## Inhalt

| Seite | Datei |
|---|---|
| Startseite | [`index.html`](index.html) |
| Produktseite (Beispiel 24H Hydra Boost Cream) | [`produkt.html`](produkt.html) |

## Technik

- Reines HTML und CSS, ein kleines Skript für das mobile Menü ([`menu.js`](menu.js)); nur relative Pfade.
- Keine Cookies, keine Formulare, keine Inhalte von fremden Servern (Schriften liegen in [`fonts/`](fonts/)).
- `noindex, nofollow` auf jeder Seite und [`robots.txt`](robots.txt): Suchmaschinen sollen den Prototyp nicht
  aufnehmen.
